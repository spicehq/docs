# Community Plan

The Community Plan provides one free Spice project per organization.

### Inactivity Auto-Pause

Projects that remain inactive for 7 days are automatically paused.

Paused projects can be restored through the portal at any time. A project is considered active on a given day if it receives at least one API request using its API key.

[Paid plans ](plans.md)do not auto-pause.
